# Paten Pikku AI Helper

Pieni, paikallisesti ajettava selainapuri. Käyttöliittymä pitää viimeiset 12 viestiä muistissa vain selainistunnon ajan.

## Käynnistys

1. Kopioi `.env.example` tiedostoksi `.env`.
2. Lisää `.env`-tiedostoon oma `OPENAI_API_KEY`.
3. Aja `npm install`.
4. Aja `npm start`.
5. Avaa selaimessa `http://localhost:3000`.

Älä laita `.env`-tiedostoa GitHubiin tai lähetä API-avainta viestillä. Avain pysyy palvelimella; selain ei näe sitä.
